Ground levels are measured at the outer shoulder edges, relative to finished centreline. Initial +1 / −1 m values demonstrate mixed cut/fill only; replace them with survey values. Scope & Review Notes

Adopted values are retained when controls change. Blank lines require project review. Radius, grade and passing-distance baselines do not become valid for a changed design speed automatically. Check alignment, drainage, capacity, pedestrian conditions and departures separately. Pavement thickness requires the pavement design tool; it is not inferred from road classification.

For arterial/urban functional settings, select a project speed: §3.4 provides context-dependent ranges rather than a single terrain lookup. Rural collector ADT 400 uses the higher band; 2,000 uses the middle band. Local-road shared boundaries use the higher band.
