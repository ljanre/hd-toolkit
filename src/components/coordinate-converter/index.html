Reference & Input Guide

PRS92 zones I–V use EPSG:3121–3125. WGS 84 latitude/longitude uses EPSG:4326. Enter projected coordinates in metres and geographic coordinates in decimal degrees.

Datum conversion uses EPSG operation 15708, Coordinate Frame rotation. Province and municipality suggestions are screening aids from DENR DMC 2010-13, Annexes VI–VII; the approved survey plan governs.

Horizontal coordinates only; assumed ellipsoidal height is zero. Elevation is not converted. Verify survey work with the responsible geodetic engineer.
