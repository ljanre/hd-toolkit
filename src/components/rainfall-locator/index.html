PAGASA Rainfall Station Locator

Road Drainage & Stormwater Design Reference Tool

Identify nearby PAGASA rainfall and climate stations for preliminary hydrologic data screening. This tool locates candidate stations to investigate — it does not select a design station or produce rainfall values automatically.

Engineering Use Notice

This application is an engineering reference and station-location tool only. The geographically nearest PAGASA station is not automatically the appropriate station for hydrologic or drainage design. Final rainfall-station selection must consider record length, data quality, elevation, topography, watershed characteristics, climatic representativeness, and applicable PAGASA, DPWH, NHRC, LGU, or project-specific requirements.

Rainfall intensity, IDF values, design storm depths, discharges, and drainage structure dimensions must be verified and calculated by a qualified engineer using authoritative data and applicable design standards. Station locations and metadata should be verified against current PAGASA records before final design.

Not an official PAGASA or DPWH application.

About This Tool & Data Sources

Climate/Synoptic station list (55 stations) compiled from PAGASA's Climatology and Agrometeorology Division published Climatological Normals (1991–2020) station index, cross-checked where possible against PAGASA's automated network coordinate exports and the PANaHON hydromet portal. Location search uses OpenStreetMap Nominatim (free public geocoder) for coordinates, and a PSGC-based public dataset for the province/municipality dropdowns — nothing is sent anywhere except those lookups. Full source-by-source documentation is in data-sources.md.

Reminder: Station locations and metadata should be verified against current PAGASA records before final design. Rainfall intensity, IDF values, design storm depths, discharges, and drainage structure dimensions must be verified and calculated by a qualified engineer using authoritative data and applicable design standards.
