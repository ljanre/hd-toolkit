Calculation Steps

  1. Enter AADT Values

    Use annual average daily traffic by vehicle class from the applicable traffic study. A short-duration count requires the study’s adjustment procedure before entry here.

  2. Calculate Each Row Total

    AADTrow = Σ AADTvehicle class Eq. (1)

    Sum the ten entered vehicle classes for that row. Blank cells are not assumed to be zero.

  3. Summarize Entered Rows

    AADTclass,total = Σ AADTrow,class Eq. (2)

    AADTtotal = Σ AADTclass,total Eq. (3)

    The total is an arithmetic worksheet sum. Enter only non-overlapping components for the same design location and study period; avoid combining separate stations or repeated counts.

  4. Specify Growth Rates

    Enter the adopted annual percentage for each class. Choose one shared rate or enter rates by vehicle class in the CESAL table. Growth does not change current AADT. CESAL Calculation Steps & References

Checked against DPWH Design Procedure Manual for Roads (2017), §§1.1.1–1.1.3, page 13; Table 1, page 124. The manual’s fourth-power axle method is separate from AASHTO Appendix D factors.

  1. Project Survey AADT to Opening

    AADTopening,i = AADTsurvey,i × (1 + ri)ᵐ Eq. (4)

    i = vehicle class; ri = annual growth percentage ÷ 100; m = whole years to opening. Rates come from the shared Annual Growth input or the editable Annual Growth column in the vehicle table. Counts are two-way; if already directional or design-lane counts, set the corresponding factor to 1 to avoid reducing them twice.

  2. Accumulate Design-Life Traffic

    Gi = [(1 + ri)ⁿ − 1] / ri; Gi = n when ri = 0 Eq. (5)

    n = whole design years. This geometric sum covers opening year through year n − 1, with the first year at opening AADT. It assumes constant annual growth, distribution and vehicle factors. Declining traffic is allowed when r > −1.

  3. Calculate Design-Lane Vehicles and ESAL

    Ni = 365 × AADTopening,i × Gi × DD × DL Eq. (6)

    CESALi = Ni × EFi; W18 = Σ CESALi Eq. (7)

    EF is ESAL per vehicle, including all its axles. Use class-average factors derived from the project axle-load distribution and applicable AASHTO pavement assumptions. The broad 3+ and 5+ axle classes need weighted factors for their actual mix. Gross vehicle weight alone does not determine an AASHTO rigid EF. Zero-traffic classes contribute zero; active classes require explicit factors, including 0 when justified.

  4. DPWH Axle-Load Method

    EF = Σ(Laxle / 8.2)⁴ Eq. (8)

    Laxle = physical axle load in metric tonnes. Enter measured or adopted design axle loads; GVW alone does not define their distribution. A class containing several configurations requires a weighted class factor. The manual page 18 has conflicting 3-axle numbers: its diagram uses 6.66, 13.32, 13.32 t (EF ≈14.36), while its displayed formula uses 5.45, 10.9, 10.9 t (EF ≈6.44). The toolkit calculates the entered loads rather than forcing a printed result.
