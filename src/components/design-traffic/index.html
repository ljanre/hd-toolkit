Truck Configurations & Equivalent Factors

Loading Case Input Guide

Configuration
Select the matching axle arrangement. Add separate rows for different weights; avoid counting the same vehicles twice.
Survey AADT
Enter annual-average two-way vehicles/day, rather than raw short-duration counts. Blank rows are excluded; zero contributes zero.
GVW and axle fractions
Enter gross vehicle weight in kg and one comma-separated fraction per physical axle. Fractions must total 1 (rounding tolerance 0.001); entered shares are not normalized. Catalogue weights are reference loading cases.
Equivalent factor (EF)
Calculate from axle fractions or enter a verified ESAL/vehicle factor. Automatic EF = Σ(axle load in tonnes / 8.2)⁴. Active traffic with missing EF keeps W18 pending.
Result
Total design-lane CESAL equals W18. DD and DL apply once. Verify the adopted loading factors before applying to Rigid Pavement.
