# Input Defaults

HD Toolkit uses the lower end of a documented recommended range only when the input does not require choosing a project condition. Numerical validation limits and chart boundaries are not recommendations.

| Tool | Starting values and basis |
| --- | --- |
| Rigid Pavement | User-requested **rural lower-volume collector, two lanes total** starting case: R=85%, So=0.30, p₀=4.5, pₜ=2.0, traffic=15.00 million ESAL, f′c=3,500 psi (equivalent to approximately 24.132 MPa; Use MPa toggle available), Cd=1.00, J=3.8. This reference loading gives a calculated 290.796 mm slab, rounded upward to **300 mm** at 10 mm increments, over **200 mm** subbase. Traffic is an example assumption chosen for the requested default section; it is not a universal minimum or a substitute for the project CESAL study. R is the requested reliability default; So is the supplied rigid-range lower value. Traffic and material/configuration values are explicit assumptions, not universal recommended minima. Foundation mode is automatic: DSB=200 mm (7.87 in), ESB=15,000 psi, MR=1,000 psi (moduli use Figure 3.3 lower plotted bounds), LS=1 for assumed unbound granular material; kcorr rounds to 34 pci. These are a starting chart case, not measured foundation properties. Specified flexural strength Sc defaults to 550 psi (14-day worksheet specification toggle); turning it off enables a project value. S′c = Sc + |ZR| × (PS/100) × Sc; PS follows the requested reliability coupling. Ec remains independent and calculated from f′c. ZR and ΔPSI calculate automatically. |
| Pavement Illustration | Uses Foundation Support Subbase Thickness directly (default 200 mm). Auto mode uses the same thickness for kcorr; with auto-calculate off, thickness remains editable for drawing while kcorr is entered independently. |
| Concrete Modulus of Rupture | Reliability and concrete strength start blank. Manual PS and z also start blank; reliability-linked PS and z remain automatic. |
| Corrected Subgrade Reaction | Soil strength, subbase depth/modulus, effective k and loss of support start blank. Chart-domain lower bounds do not select a material or foundation condition. |
| Determining Subbase Thickness | Traffic and Design CBR start blank; chart limits are not project recommendations. |
| Determining Design CBR | Measured CBR rows start blank. The fine-grained, soaked CBR confirmation remains checked as requested and must match the actual test conditions. |
| Coordinate Converter | Coordinates, province and source PTM zone start blank. A selected province can determine its zone; the reverse conversion retains its location-based auto-zone option. |
| Rainfall Station Locator | Project coordinates start blank. Search radius and result-count settings remain search preferences. |

Rounding increments and tool/method selections remain interface preferences. Existing saved rigid pavement cases still restore their entered values. **Reset to Defaults** replaces the prior rigid case with the collector assumption preset. Other tools retain project-input blanks unless separately documented. Design Traffic starts with truck codes 1-1, 1-2, 11-1, 12-2, 11-11 and 12-12, in that order, each with zero AADT; all catalogue types remain selectable. Traffic Survey Year and Opening Year both default to the current year from the browser’s local date on load and Clear. Zero Survey AADT clears on focus and returns to zero when left empty. Other defaults are a 20-year design period, example growth 2%, DD=0.50, and one lane per direction with DL=100% (1.00). Clear restores these defaults. Legacy case migration retains its explicitly documented 24 MPa fallback.

Shoulder Design starts OFF. When ON, the mainline CESAL remains unchanged and read-only in gray; a green editable shoulder field starts at 10% of it. The adopted shoulder value is used directly for slab design, illustration and capacity checks; it is not multiplied by 10% again. Manual edits retain full precision and survive unrelated input changes, toggling and local restore. Reset clears the override. The local saved case retains the original CESAL, shoulder load, manual-override flag and shoulder-mode flag. Turning OFF restores the original mainline design; Reset turns the shoulder mode OFF. The guide cites the supplied DGCS “Shoulder Design” excerpt and its full-traffic exception. The supplied page locator is DGCS Volume 4, p.6-143, “Shoulder Design”; the AASHTO Chapter 1.9 reference is kept distinct.
